## 二、每天它会做什么（6 步）

1. 客户端没开就启动，开了就激活窗口（**这一步是“当日首次登录”**，每日免费积分就是靠首次登录发放的）；
2. 先扫 12 秒，**如果当天首次打开时弹了「立即签到」，就直接点掉**，并记录“点击后签到入口是否消失”；
3. 点左下角头像（用 UI 自动化定位账号按钮「奔走四方 标准套餐」并点它中心，不依赖固定坐标），读出 `可用额度 X` 和 `N 次额度重置`；
4. 调菜单项「免费用豆包工作」打开额度页（只认菜单项，不会误点到同名标签页/侧栏项目）；
5. 在额度页里按名字找「签到」类可点击按钮：找到就点；找不到就记录状态并关掉该标签页，不瞎点；
6. **领取后复核额度**：再读一次 `可用额度`，和上次日志里的数值对比，直接写进日志，例如
   `签到后可用额度 可用额度 9,074（上次记录 8905，变化 +169）`。读不到就记 WARN，不算失败。

## 四、v3 相对 v2 修了什么

| 问题 | v2 表现 | v3 处理 |
| --- | --- | --- |
| 领完不核对 | 点完签到就 `exit 0`，额度有没有涨不知道 | 新增领后读额度 + 与上次日志对比，写进日志 |
| 窗口误选 | “标题含豆包 + 最宽”会选中**豆包浏览器**（1874×1096），而不是客户端（1200×800） | 统一按“进程名 Doubao + 大窗口”收集，再排除 `浏览器/AIEP`、要求标题含豆包且可见 |
| 窗口偶尔枚举不到 | 直接 `exit 1` | 找不到可见窗口时扫“隐藏/最小化窗口”，`SW_RESTORE + SW_SHOW + MoveWindow` 恢复出来再继续；仍不行才重新唤起客户端 |
| 头像点不开菜单 | 固定坐标 `(223,926)`；改用 `InvokePattern` 也常点不开 | 用 UI 自动化**定位账号按钮并按真实鼠标点击其中心**（Electron 菜单只认真实点击） |
| 读额度误命中聊天正文 | 页面上有“可用额度/额度重置”字样就会被当菜单 | 只认**小尺寸节点**（宽<320、高<90）+ 必须解析到数字才算成功 |
| 找不到客户端 exe | 只查 `%LOCALAPPDATA%` 三个路径（本机实际是 `C:\Sofaware\Doubao\app\Doubao.exe`） | 先从运行中的进程读 `Path`，再回退候选路径 |

## 五、关于每日免费积分

官方规则：每日免费积分在**当日首次在移动端/PC 端登录豆包时自动发放**，当天 24:00 清零，不需要点。

如果客户端整夜不关，第二天可能没有新的“首次登录”。需要时可以打开顶部开关：

```powershell
$RestartClient = $false   # 改成 $true：每天 07:10 先关掉豆包再重开，强制触发首次登录
```

默认 `$false`（不动你的客户端）。

## 六、可调参数（脚本顶部）

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `$WinX/$WinY/$WinW/$WinH` | 158/162/1200/800 | 客户端窗口固定位置与大小 |
| `$AvatarRelX/$AvatarRelY` | 65/764 | 头像相对坐标（仅当 UI 自动化定位失败时兜底） |
| `$PageWait` | 7 | 打开额度页后等待秒数 |
| `$PopupWait` | 12 | 等待签到弹窗出现的最长秒数 |
| `$CreditRetries` | 4 | 读额度最多尝试次数 |
| `$VerifyCredit` | `$true` | 是否做领后额度复核 |
| `$RestartClient` | `$false` | 是否每天先重启客户端 |

## 七、退出码

- `0` 成功点掉签到（或今日已完成）
- `2` 没找到可点的签到入口（已记录并关掉标签页）
- `1` 客户端窗口/菜单/额度页打不开

## 八、前提与维护

- 07:10 需要开机 + 已登录桌面（任务里可勾选“唤醒计算机运行此任务”）；笔记本注意接通电源。
- 这台机器有**两个登录会话**（控制台会话 1、远程桌面会话 3），客户端跑在会话 1。脚本必须跑在**和客户端同一个会话**里才能看到窗口；日志第一行会打印 `脚本所在会话=x；客户端进程所在会话=y`，两者不一致就是会话隔离导致的“看不到窗口”。
- 豆包必须保持登录；退出登录后脚本会停在“找不到菜单项”。
- 界面改版时改脚本顶部参数即可。
- 停用：任务计划程序里删除「豆包每日自动领取积分」，脚本本身不改动任何系统设置。
- 回滚：同目录 `doubao_daily_claim.v2.bak.ps1` 是升级前的 v2 备份。

## 九、和更早版本的区别

- **v1**（截图 + OCR + 固定坐标）：会误判，把普通对话界面当成额度页。
- **v2**（Windows UI 自动化按控件名操作）：能准确点菜单、读额度，但**点完签到不核对**，且窗口/头像两处容易被环境影响。
- **v3**（本版）：在 v2 基础上补上“领后额度复核 + 窗口恢复 + 头像真实点击 + 节点尺寸过滤”，把每天的**动作**和**结果**都落进日志。
